# Mills McIlroy — Personal Site

A concise personal site focused on software engineering capabilities, technical interests, and contact information. It intentionally avoids résumé-style employment history, employer names, role timelines, and downloadable CV content.

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- Vercel Analytics

## Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run build
```
